# Practice set 3

Twenty problems in a fixed order. Each line points at one practice file: the
statement is in the header comment, the method body is empty, and the test
runner is below it. Copy the file, write the body, run it.

```
javac --release 8 <ClassName>.java && java <ClassName>
```

Say the time and space complexity before the first line. Trace the smallest
input before calling it done. Stop at 25 minutes.
